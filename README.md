# 1pop-RD-ES-2p-2a
This is a Mathematica notebook created to analyze the Replicator Dynamics in 2-player 2-action repeated games with Endogenous Separation. 

It shows the expected payoff of each of two strategies and the phase portrait of the one-population replicator dynamics with endogenous separation.

Authors: <a target="_blank" href="http://luis.izqui.org">Luis R. Izquierdo</a> &amp; <a target="_blank" href="http://segis.izqui.org">Segismundo S. Izquierdo</a>
